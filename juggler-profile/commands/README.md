# Global slash komutları

Buraya konan komut dosyaları `JUGGLER_CONFIG_DIR/commands/` altına kurulur ve
**her projede** kullanılabilir olur.

ATLAS'ın `/atlas-section` komutu buraya değil, eklentinin içinde durur
(`extensions/atlas-engineering/commands/`) — eklenti komutları yetenekleriyle
birlikte sürümlenir ve `juggler ext validate` denetiminden geçer. Bu klasör,
eklentiye bağlı olmayan serbest komutlar içindir.
