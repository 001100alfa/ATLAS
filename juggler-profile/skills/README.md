# Juggler skill paketleri

Buraya konan skill klasörleri `JUGGLER_CONFIG_DIR/skills/` altına kurulur
(Juggler'ın "user" kapsamı) ve panelde her projede görünür.

ATLAS'ın kendi alan bilgisi (`skills/engineering`, `skills/trading`) Claude Code
biçimindedir ve ajanın kendisi tarafından okunur — Juggler skill biçimi değildir.
Juggler'a taşınacak bir skill hazırlanırsa buraya konur; senkron kurar.
