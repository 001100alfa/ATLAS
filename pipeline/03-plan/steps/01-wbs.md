# 01 — İş Kırılımı  `/wbs`

**Amaç:** Spec'i <= yarım günlük iş paketlerine bölmek.

| | |
|---|---|
| **Girdi** | ONAYLI SPEC |
| **Çıktı** | WP tablosu (çıktı + doğrulama tanımlı) |

## Prosedür
1. Her WP'nin çıktısı somut dosya/fonksiyon olmalı.
2. Her WP'nin doğrulaması: hangi test/komut yeşil olacak?
3. Yarım günden büyük WP -> böl.

## Kapıya Katkısı
Gate: 'her paket <= yarım gün' sağlanır.
