# 01 — Dal Açılışı  `/branch`

**Amaç:** Temiz başlangıç: branch + iskelet dizinler.

| | |
|---|---|
| **Girdi** | PLAN-XXX.md |
| **Çıktı** | feat/task-XXX branch + boş modül iskeleti |

## Prosedür
1. main güncel mi? pull. Sonra branch aç.
2. Modül/test dosyalarını BOŞ iskelet olarak oluştur, commit et.
3. Bu commit 'sıfır noktası' — sonraki diff'ler temiz okunur.

## Kapıya Katkısı
İzlenebilir, geri alınabilir başlangıç.
