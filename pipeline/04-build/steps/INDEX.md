# 04-build alt-beceri zinciri

01. **Dal Açılışı** `/branch` — Temiz başlangıç: branch + iskelet dizinler.
02. **TDD Çekirdeği** `/tdd-core` — Önce kabul testini yaz (kırmızı), sonra kodu (yeşil).
03. **Paket Yürütme** `/execute-wp` — WP'leri sırayla kapatmak, her biri commit'le.
04. **Sapma Dedektörü** `/drift-check` — Spec dışına kaymayı erken yakalamak.
05. **Build Kapanışı** `/close-build` — BUILD log'u tamamlayıp test aşamasına devretmek.
