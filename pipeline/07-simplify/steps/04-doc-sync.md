# 04 — Doküman Senkronu  `/doc-sync`

**Amaç:** Kod ile dokümanın aynı gerçeği anlatmasını sağlamak.

| | |
|---|---|
| **Girdi** | Sadeleşmiş kod |
| **Çıktı** | Güncel docstring/README/CHANGELOG taslağı |

## Prosedür
1. Her değişen imzanın docstring'i güncel mi?
2. README örnekleri hâlâ ÇALIŞIYOR mu? (kopyala-koştur testi)
3. Silinen özellik dokümandan da silinir — hayalet doküman yasak.

## Kapıya Katkısı
Doküman güvenilir kalır.
