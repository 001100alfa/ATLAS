# 01 — PROMPTS (Yönerge Mühendisliği)
**Amaç:** NEED'i ajanın yanlış anlayamayacağı yönergeye çevirmek.
Belirsiz istek = belirsiz kod. Bu aşama halüsinasyon sigortasıdır.
**Girdi:** Onaylı NEED-XXX.md
**Çıktı:** `PROMPT-XXX.md` — spec üretimini yönetecek ana yönerge.

## Çıkış Kapısı
- [ ] Rol, bağlam, görev, format, kısıt ayrı bölümlerde
- [ ] En az 1 pozitif + 1 negatif örnek var
- [ ] Hangi skills/SKILL.md okunacağı listelendi
- [ ] Belirsiz terim kalmadı (her terimin birimi/tanımı var)
