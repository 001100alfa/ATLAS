# 07 — Beceri Damıtma  `/write-a-skill`

**Amaç:** Bu görevde öğrenilen genellenebilir kuralı skills/'e bottlelamak.

| | |
|---|---|
| **Girdi** | Final yönerge + görüşme notları |
| **Çıktı** | skills/ altında yeni/güncellenmiş SKILL.md bölümü |

## Prosedür
1. Sor: bu kural GELECEK görevlerde de geçerli mi?
2. Evetse ilgili SKILL.md'ye kısa kural olarak ekle (tarih + görev no).
3. Hayırsa sadece PROMPT'ta kalır — skill şişirilmez.

## Kapıya Katkısı
Kurumsal hafıza büyür; tekrar iş azalır.
