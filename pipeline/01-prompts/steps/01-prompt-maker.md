# 01 — Prompt Maker  `/prompt-maker`

**Amaç:** Onaylı NEED'i ilk taslak yönergeye dönüştürmek: dağınık->yapılı.

| | |
|---|---|
| **Girdi** | NEED-XXX.md |
| **Çıktı** | PROMPT-XXX.draft.md (rol/bağlam/görev/format/kısıt iskeleti) |

## Prosedür
1. NEED'deki problemi GÖREV cümlesine çevir (tek eylem).
2. Rol ata: hangi uzmanlık şapkası? (ör. EN 1993 + Python)
3. Bağlam bölümüne: ilgili src/ modülleri, DECISIONS kayıtları.

## Kapıya Katkısı
Yapılı taslak var; sonraki adımlar bunu rafine eder.
