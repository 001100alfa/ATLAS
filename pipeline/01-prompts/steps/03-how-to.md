# 03 — How To  `/how-to`

**Amaç:** Görevin gerektirdiği ama henüz bilinmeyen adımları haritalamak.

| | |
|---|---|
| **Girdi** | Netleşmiş taslak |
| **Çıktı** | Bilgi boşluğu haritası + okunacak kaynak listesi |

## Prosedür
1. Görevi kabaca adımlara böl; her adım için 'nasıl yapılır biliniyor mu?'
2. Bilinmeyenler için: skills/ dosyası mı, standart mı, researcher subagent mı?
3. Okunacaklar listesini PROMPT'un Bağlam bölümüne yaz.

## Kapıya Katkısı
Gate: 'okunacak skills listelendi' sağlanır.
