# 05 — Açık Soru Avı  `/open-questions`

**Amaç:** Onay öncesi tüm kararsızlıkları yüzeye çıkarmak.

| | |
|---|---|
| **Girdi** | Spec taslağının tamamı |
| **Çıktı** | Açık soru listesi (sahipli, son tarihli) |

## Prosedür
1. Taslağı satır satır oku: 'burada iki türlü anlaşılır mı?'
2. Her açık soru: kim cevaplayacak + hangi adımda bloklar.
3. Sıfır açık soru şüphelidir — en az bir tur zorunlu.

## Kapıya Katkısı
Onaya temiz spec gider; build sürprizi azalır.
