# 01 — Gereksinim Çıkarımı  `/fr-extract`

**Amaç:** PROMPT'tan numaralı, test edilebilir FR'ler türetmek.

| | |
|---|---|
| **Girdi** | PROMPT-XXX.md |
| **Çıktı** | FR-1..N tablosu (taslak) |

## Prosedür
1. Her FR tek cümle, tek doğrulanabilir davranış.
2. 've' içeren FR'yi ikiye böl.
3. FR'ler NEED başarı ölçütlerini TAM kapsıyor mu çapraz kontrol.

## Kapıya Katkısı
FR listesi izlenebilirliğin temelini atar.
