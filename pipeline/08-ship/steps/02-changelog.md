# 02 — Changelog Yazımı  `/changelog`

**Amaç:** Değişiklikleri kullanıcı diliyle kaydetmek.

| | |
|---|---|
| **Girdi** | Commit geçmişi |
| **Çıktı** | CHANGELOG.md girdisi |

## Prosedür
1. Keep-a-Changelog: Eklendi/Değişti/Düzeltildi/Kaldırıldı.
2. Commit mesajı kopyalama — KULLANICI etkisini yaz.
3. Kırıcı değişiklikler EN ÜSTTE, geçiş talimatıyla.

## Kapıya Katkısı
Sürüm geçmişi okunabilir kalır.
