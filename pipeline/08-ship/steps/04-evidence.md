# 04 — Kanıt Dosyası  `/evidence`

**Amaç:** NEED'deki başarı ölçütünü ÖLÇÜP kapatmak.

| | |
|---|---|
| **Girdi** | NEED-XXX ölçütleri + yayın |
| **Çıktı** | SHIP-XXX.md kanıt bölümü |

## Prosedür
1. NEED'e dön, her ölçütü tek tek ÖLÇ (tahmin değil).
2. Ölçüm çıktısını rapora yapıştır (test çıktısı, süre, karşılaştırma).
3. Sağlanmayan ölçüt varsa ship DURUR — geriye hangi aşama, belirle.

## Kapıya Katkısı
Gate: 'başarı ölçütü kanıtı' sağlanır.
