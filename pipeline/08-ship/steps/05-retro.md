# 05 — Retrospektif  `/retro`

**Amaç:** Süreci puanlayıp pipeline'ın kendisini iyileştirmek.

| | |
|---|---|
| **Girdi** | Tüm görev artefaktları |
| **Çıktı** | Retro notu + pipeline iyileştirme önerisi |

## Prosedür
1. Hangi aşama en çok zaman yedi? Gate'lerden hangisi iş yaramadı?
2. 1 somut pipeline iyileştirmesi öner (şablon/komut/gate değişikliği).
3. DECISIONS'a işle; kullanıcıya tek paragraf teslim özeti ver.

## Kapıya Katkısı
Pipeline yaşayan sistem olur — kendi kendini iyileştirir.
