# 02 — Sorgu Yağmuru  `/grill-need`

**Amaç:** Belirsiz hiçbir şey kalmayana kadar soru sormak.

| | |
|---|---|
| **Girdi** | RAW-XXX.md |
| **Çıktı** | Cevaplanmış soru listesi (NEED'in hammaddesi) |

## Prosedür
1. Kim kullanacak? Ne sıklıkla? Neyin yerine geçiyor?
2. Yanlış olursa ne kaybedilir (para/zaman/güvenlik)?
3. Soruları TOPLU sor (tek mesaj), cevapları kaydet.
4. Cevapsız soru = NEED'e 'Açık Soru' olarak taşınır.

## Kapıya Katkısı
Problem tek cümlede yazılabilir hale gelir.
