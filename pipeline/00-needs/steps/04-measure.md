# 04 — Ölçüt Mühendisi  `/measure`

**Amaç:** Başarıyı sayıya bağlamak. Ölçemediğin şeyi teslim edemezsin.

| | |
|---|---|
| **Girdi** | Kapsam listesi |
| **Çıktı** | Sayısal başarı ölçütleri (tolerans + kaynak) |

## Prosedür
1. Her ölçüt: <metrik> <karşılaştırma> <değer> <koşul>.
2. Ör: 'Iy, katalog değeriyle ±%3 içinde (fillet farkı gerekçeli)'.
3. Ölçülemeyen istek varsa 02'ye dön, soruyu netleştir.

## Kapıya Katkısı
Gate: 'başarı ölçütü sayısal/doğrulanabilir' işaretlenir.
