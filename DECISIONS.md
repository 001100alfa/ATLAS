Juggler çekirdeği AGPL-3.0 ama ayrı derlenir/çalışır (bundle'a gömülmez). Yetenekler: `atlas_section`/`atlas_recall` context-item araçları, `/atlas-section` komutu, sistem-prompt katkısı; ATLAS launcher'larına `juggler/ops` shell köprüsü (PATH'ten).
- [KARAR] Eklentinin stabil sözleşmesi için `atlas-sections --json` eklendi (properties+units, hata JSON'u stderr/exit 2). Metin parse'a bağımlılık = kırılganlık.
- [KARAR] Yedek AI CLI'ları: OpenCode (`opencode-ai`) + Kilo (`@kilocode/cli`) proje-yerel npm kurulumu (`tools/ai-cli/`, `setup-ai-cli.cmd`), Claude Code limitinde/tercihe göre. Config/data proje içine hapsedilir; kullanıcı home'una dokunulmaz. Başlatıcılar `opencode_Run.cmd`/`kilo_Run.cmd`. node_modules+home gitignore, package(-lock).json tutulur.
- [KARAR] Juggler ACP Agents için 5 yedek ajan: opencode/kilo/cline (npm), kimi (pip, `tools/ai-cli/py-venv`), goose (Windows binary `tools/goose/`, v1.44.0). Hepsi stdio ACP handshake ile doğrulandı (opencode 1.18.4, kilo 7.4.15, cline 3.0.46, kimi 1.49.0, goose 1.44.0). `gen-acp-config.js` varlık-kontrollü (yalnız kurulu olanı yazar); `setup-ai-cli.cmd` üç ekosistemi de kurar. goose/py-venv gitignore.
- [HATA] goose zip'i bsdtar/PowerShell ile açılmıyor (`-5 decompression failed` / corrupt 244M binary → segfault). Ayrıca gh release download yarımken açmaya çalışmak "not a zip" verdi. Çözüm: indirme tam bittikten sonra **Python `zipfile`** ile aç (deflate, 244M goose.exe sağlam). setup-ai-cli.cmd goose'u python zipfile ile açar.
- [HATA] Kimi ACP `printf | kimi acp` ile yanıt vermiyordu — pipe stdin'i EOF ile kapatıyor, kimi'nin async sunucusu yanıt veremeden ölüyor. Juggler stdin'i açık tutar → sorun yok. Doğrulama testleri stdin'i açık tutmalı (verify_acp.js gibi).
- [HATA] Juggler "ACP Agents" panelinde kilo/opencode çalışmıyordu: Juggler ajanı `exec.LookPath(command)` + doğrudan `exec.Command` ile spawn eder (kabuk yok). `command:"kilo"` PATH'te yok (proje-yerel); `.cmd` shim'i PE olmadığından Go exec ile çalışmaz. Çözüm: `setup-acp-agents.cmd` + `tools/gen-acp-config.js` → `<project>/.juggler/acp.json` üretir: kilo `command:"node" args:[<bin>,"acp"]`, opencode `command:<opencode.exe abs> args:["acp"]`, env ile config/data proje-yerel. Juggler env'i parent+config olarak merge eder. Her iki ajan da ACP initialize'a yanıt verecek şekilde doğrulandı (Kilo 7.4.15, OpenCode 1.18.4). acp.json makineye özel → gitignore; generator tutulur.
